🧠 MindCare — Mental Wellness Web Application
MindCare is a mental wellness web application designed to support emotional well-being through a calm, welcoming, and visually soothing digital experience. The homepage serves as a peaceful introduction to the platform, encouraging users to explore its features and prioritize their mental health.

🎯 Purpose
The MindCare homepage is designed to:

Create a peaceful and positive first impression
Promote mental wellness awareness
Encourage users to explore the platform
Provide a visually relaxing, distraction-free experience


✨ Features

Full-screen calming background — an immersive, serene visual sets the tone
Motivational wellness quotes — uplifting messages to support a positive mindset
Minimal, clean UI — simple layout that keeps the focus on well-being
Responsive design — adapts seamlessly to different screen sizes and devices
Beginner-friendly structure — easy to understand, modify, and build upon

▶️ Getting Started

Download or clone the repository to your local machine
Open the project folder
Launch homepage.html in any modern web browser (Chrome, Edge, Firefox, etc.)


No installation or build tools required — it runs entirely in the browser.
